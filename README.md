# Todo List

A React + Vite todo app with TypeScript, Tailwind CSS, local persistence, and a confirmation step before deletes.

## Scripts

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Command | What it does |
| --- | --- |
| `npm run dev` / `npm start` | Start the Vite dev server |
| `npm test` | Run unit tests once |
| `npm run build` | Type-check and create a production build in `dist/` |
| `npm run preview` | Preview the production build |

Todos are saved in `localStorage`, so they stay after a refresh.
